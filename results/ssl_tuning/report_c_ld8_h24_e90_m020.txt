SBGI Concept Implemented
------------------------
SBGI (Satellite-Based Groundwater Index) is implemented as:
SBGI = ((GRACE anomaly + precipitation) * sqrt(soil moisture)) / (elevation + 1e-6)
SBGI-geology interaction is implemented as:
SBGI_geology = SBGI * (0.8 + 0.4 * geo_cluster)

These features are used directly in prediction: sbgi, sbgi_geology.
Legacy aliases are preserved for compatibility: groundwater_index, gwi_geology.
